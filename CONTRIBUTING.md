# Contributing

- Keep the selected Fandom Wiki continuity separate from other Backrooms canons.
- Do not add an entrance, exit, entity ability, or level detail without an individual source page.
- Keep each released level to one or two selected documented entrances and exits.
- Add or update tests whenever validation or transition behavior changes.
- Keep common initialization dedicated-server safe.
- Avoid per-tick global scans and unbounded world-generation work.
- Run `gradle --no-daemon clean build` before submitting changes.
- Group related work into coherent changes rather than unnecessary micro-commits.
